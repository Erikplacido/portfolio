Ativação de Marca · CCXP & Netflix

Da fila de espera ao solo de metal no estande de Stranger Things.

Projetado para o estande temático do Hellfire Club na CCXP (Comic Con Experience), o advergame resolve o estresse de filas de espera de mais de 1 hora: o visitante escaneia o QR Code nas divisórias da fila, carrega o game no navegador do celular em menos de 2 segundos (sem download de app na loja) e, se fechar a faixa com Rank A ou S, retira palhetas metálicas colecionáveis e bottons diretamente no balcão.

Briefing de Ativação: Criar um advergame mobile de ritmo rápido e viciante com estética 16-bits dos anos 80, sem atrito de instalação, capaz de reter o público na fila, gerar competição espontânea entre os visitantes e entregar um brinde físico de alto valor emocional.
1:01de música por partida a 132 BPM, calibrada para a rotação rápida da fila
5pistas coloridas e numeradas (A, S, D, F, G ou touch responsivo para celulares)
0sde download: 100% web nativo com Web Audio API e Canvas a 60 fps
~32%dos participantes atingem Rank A/S e resgatam o brinde no estande

01 · O jogo

Cinco pistas, uma linha, nenhum lugar para se esconder.

As notas descem pelo braço da guitarra e o acerto é na linha iluminada. Notas com cauda pedem para segurar; na dificuldade Lenda, acordes chegam juntos exigindo múltiplos toques. A música segue até o fim sem interrupção mesmo com erros. Toque aqui no palco interativo ou abra a versão completa em tela cheia.

02 · Arquitetura Técnica & Engine de Ritmo

AudioContext Clock vs. requestAnimationFrame: A sincronia de áudio em milissegundos.

Por que jogos de ritmo em HTML5 costumam falhar e como o motor do Hellfire Overdrive alcançou precisão cirúrgica de áudio sem drift temporal, suportando compensação milissegundo a milissegundo para fones Bluetooth.

AUDIO THREAD (Hardware DSP) AudioContext.currentTime a 44.1 kHz. Relógio mestre imutável e livre de garbage collection ou throttling de CPU.
⇄
RENDER THREAD (Canvas 60/120 fps) requestAnimationFrame apenas projeta espacialmente as notas: Y(t) = hitY − (Tnota − Tgame) × V.
Web Audio API

Relógio Mestre em Hardware

Em vez de confiar em timers convencionais de JavaScript (setTimeout ou setInterval), que sofrem variações de até 50 ms por causa de reflows da DOM ou tarefas concorrentes na main thread, o motor ancora 100% da linha do tempo em AudioContext.currentTime:

  • Thread de áudio dedicada de prioridade máxima no sistema operacional
  • Imunidade contra travamentos de Garbage Collection (GC) da V8
  • Retomada contínua após pausa sem perda cumulativa de sincronismo
Latência Bluetooth

Compensação de −200 ms a +300 ms

Fones sem fio Bluetooth (AirPods, Galaxy Buds) impõem um atraso físico de transmissão de 120 ms a 240 ms por compressão de codec (AAC/SBC). O game introduz um relógio corrigido:

  • gameClock = audioClock − (settings.sync / 1000)
  • Ao aumentar o valor, as notas descem atrasadas na tela exatamente na proporção do atraso acústico do fone
  • Garante que o impacto visual na linha coincida com o som no tímpano do jogador
Julgamento de Hit

Janelas Rígidas de Tolerância

A precisão do jogador é calculada no instante do toque comparando o timestamp da nota com o gameClock() corrente:

  • Perfeito (±50 ms): Pontuação integral, aumento de combo e recarga do Shred Meter
  • Bom (±110 ms): Pontuação parcial (50%), mantém combo sem multiplicador extra
  • Erro / Miss (> 110 ms): Zera o combo e reseta o multiplicador para ×1
APIs Móveis Nativas

Wake Lock & Web Vibration

Otimizações de engenharia essenciais para a experiência de jogo em smartphones durante ativações presenciais:

  • Screen Wake Lock API: Impede ativamente que a tela do celular apague ou escureça no meio do solo de 1 minuto
  • Web Vibration API: Disparo de pulsos hápticos nos acertos perfeitos para feedback tátil
  • Bundle 100% Inline (2,2 MB): Todo o jogo (áudio base64, spritesheets e motor) carrega em menos de 2 segundos
// Trecho real do motor de sincronia de áudio e compensação Bluetooth (game.html)
function audioClock() {
  return source ? Math.max(offset, offset + audioContext.currentTime - startAt) : pausedAt;
}

function gameClock() {
  // Compensação milissegundo a milissegundo de latência acústica de fone Bluetooth
  return audioClock() - (settings.sync / 1000);
}

function checkHit(lane, inputTime) {
  const note = findNextPendingNote(lane);
  if (!note) return;
  
  const delta = Math.abs(note.time - inputTime);
  if (delta <= 0.050) {
    registerHit(note, 'PERFEITO', 1.0); // Janela cirúrgica de ±50ms
  } else if (delta <= 0.110) {
    registerHit(note, 'BOM', 0.5);      // Janela tolerante de ±110ms
  }
}

03 · Ativação & Resgate de Brinde

Rank A ou S libera o brinde colecionável no estande.

O motor calcula a precisão da sessão em tempo real. Quem fecha o solo com Rank A (≥ 88%) ou Rank S (≥ 97%) desbloqueia um voucher criptográfico com QR Code para retirada de palhetas de metal e bottons temáticos no balcão da CCXP. A demonstração automática é isolada em código para nunca liberar prêmios.
