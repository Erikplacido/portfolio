Problema de Negócio

O que motivou este projeto

"No Méliuz Cartões, os dados revelavam que muitos usuários com faturas elevadas entravam no crédito rotativo por desconhecimento das opções de parcelamento prévio da fatura. Além disso, clientes no desktop relatavam carência de recursos para organizar e auditar despesas."

O desafio foi criar uma experiência financeira unificada que educa no momento de maior vulnerabilidade, com transparência absoluta de taxas.

Decisões de UI

Anatomia Omnichannel

Mobile Dashboard 390 × 844 px

Tela 1: Dashboard e Termômetro de Limite

Visão consolidada da fatura com barra de limite bicolor, ações rápidas de pagar/parcelar e carrossel de atalhos.

  • Barra de progresso bicolor (gastos vs. limite)
  • Ações rápidas: Pagar fatura · Parcelar fatura
  • Feed de transações com ícone de categoria
Bottom Sheet Mobile Simulador · Modal

Tela 2: Simulador de Parcelamento

Bottom Sheet contextual com entrada para valor de entrada e seletor de planos com CET visível — alinhado às diretrizes do Banco Central.

  • Chips rápidos de entrada (Sem entrada, R$300, R$500)
  • 3 planos com destaque para "Mais recomendada"
  • CET, IOF e juros em caixa regulatória transparente
Desktop Web 1440 × 900 px · Alta Densidade

Tela 3: Visão Consolidada de Gastos e Limite

Experiência de alta densidade com sidebar de navegação, tabela de lançamentos filtráveis, gráfico histórico de faturas e controle granular de limite via slider interativo.

  • Sidebar fixa com navegação vertical
  • Gráfico de barras: 6 meses de faturas + média
  • Tabela de alta densidade com busca e filtros
  • Slider de ajuste de teto diário interativo

Processo de Design

Abordagens de Responsividade

Abordagem A

App Nativo com Web View Estática

O desktop seria apenas uma versão expandida do layout mobile, sem adaptação real de densidade informacional.

  • Elimina retrabalho de desenvolvimento
  • Manutenção simplificada de código
  • Consistência garantida de componentes
Escolhida

Design Responsivo Nativo por Plataforma

Cada plataforma recebe a densidade informacional adequada ao seu contexto de uso — sem sacrificar consistência de tokens e componentes.

  • Mobile: foco em ações rápidas e decisões financeiras críticas
  • Desktop: alta densidade para auditoria e controle granular
  • Tipografia tabular para dados monetários em ambas plataformas
  • Slider de limite interativo exclusivo no desktop (mais preciso)
Como foi Resolvido

Os 3 Pilares da Solução

Legibilidade de Dados Financeiros

Alinhamento numérico tabular, hierarquia tipográfica precisa para valores monetários e estados claros de fatura (aberta, fechada, paga, parcelada) eliminam a ambiguidade que levava ao crédito rotativo.

Tipografia · UX

Transparência como Diferencial Competitivo

A caixa regulatória de transparência do BACEN transforma uma obrigação legal em elemento de confiança. A auditoria sistemática de dark patterns garantiu que nenhum padrão enganoso passou pelo design.

Regulação · Trust

Paridade Visual Omnichannel

Os mesmos tokens de cor, tipografia e espaçamento (grade 4/8pt) foram aplicados em mobile e desktop — garantindo que o usuário reconheça a interface independente do dispositivo usado.
